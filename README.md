## What's new in v31.0 (September 4, 2026)
- Jetpack Compose + Material 3 shell
- Built-in TTY / ANSI terminal; module flash and action scripts
- Stream boot images from remote OTA zip URLs
- Zygisk on Android 17 / API 37 and Meta Quest Horizon OS
- Legacy View APK stays on the same tag if Compose fails

## How to use
1. Download v31.0.
2. Extract `Magisk-Desktop.zip`.
3. Point it at an apk or a boot image.
4. Patch, flash, then manage modules from the desktop window.

## FAQ

**Need a phone?**
Yes. The desktop window patches and talks to the device. Notes in `files/docs/`.

**KernelSU?**
Separate tree. This zip is Magisk v31.0 only.

## Requirements
Windows 10/11. USB debugging for flash.
